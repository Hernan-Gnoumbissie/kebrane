**GO technique (favorable).** Sur la base web + TMview, l'espace « Kebrane » est propre dans les classes 9/41/42 pour l'UE, l'Allemagne et la France. Contrairement à Orivane (marque déjà déposée et active), aucun obstacle d'antériorité n'apparaît.

**Deux réserves avant de verrouiller définitivement :**

1. **OAPI (Cameroun).** La couverture de l'OAPI dans TMview est incertaine ; ce territoire doit faire l'objet d'une **vérification directe** (base OAPI / conseil local) avant tout dépôt OAPI. → Réserve ouverte.
