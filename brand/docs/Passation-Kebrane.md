# Passation — Kebrane (à coller dans le nouveau chat)

## Où on en est
Phase de **conception terminée**. Kebrane = holding tech qui lève les barrières administratives, linguistiques et de certification entre l'Afrique francophone et l'Allemagne. Produits SaaS : GermanPass, TCFPass, PermitPass, Arrival. Divisions : Kebrane Education, Kebrane Arrival. Le système de marque complet + un **Brand Book v1.0** ont été produits.

## Décisions verrouillées
- **Nom : Kebrane** (définitif). kebrane.com déjà enregistré (IONOS).
- **Concept logo : « le A ouvert »** — soustractif : retirer la barre du A = faire tomber la barrière ; l'ouverture devient un passage. Direction retenue via grille de décision (89/100). Le tracé actuel est une *forme de travail* ; refonte confiée à un studio.
- **Charte : Georgia** (serif éditorial) — remplace l'ancien Cambria/Calibri. Navy #1F3352, Rouge #A5322C. Secondaires : Ciel #A7C4DC, Sable #ECD8BE. Neutres : Encre #1A1A1A, Papier #FBF9F5. A4, en-têtes capitales à tiret rouge, puces dash rouge, règle d'or italique bordée de rouge.
- **Architecture de marque** : symbole universel ; chaque produit se distingue par la couleur de son conteneur d'icône — GermanPass bleu ardoise #4F7CA3, TCFPass vert sauge #5F8A72, PermitPass ocre #B0893F, Arrival prune #7E6A93. Le A ne se recolore jamais ; le Marine est réservé à la marque mère ; « By Kebrane » signe les produits.
- **Usage → forme** : A nu ≥ 24 px sur fond clair ; pastille < 24 px / fond chargé / icône d'app / avatar ; favicon ≤ 20 px = pastille pixel-optimisée.
- **Règle de verrou** : jamais le symbole-A en préfixe horizontal du mot (se lit « AKEBRANE ») → verrou vertical OU A intégré uniquement.
- **Critère central du designer** : « Lu comme un A lorsqu'il porte le nom Kebrane, comme une arche ou un passage lorsqu'il est vu seul. »
