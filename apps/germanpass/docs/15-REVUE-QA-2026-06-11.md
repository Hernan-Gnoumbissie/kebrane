## 🐛 Problèmes détectés (par priorité)

### 1. Aucun bouton de déconnexion (bloquant UX)
`signOut` n'est référencé que dans `src/auth.ts`. Aucune page n'offre « Se déconnecter ». Un utilisateur sur un poste partagé ne peut pas fermer sa session.
→ Ajouter un bouton Déconnexion dans le header (`signOut()` de next-auth/react).

### 2. Le header de navigation n'existe que sur /dashboard
Le menu (Tableau de bord, Lesen/Hören, …, Mon compte, Administration) est codé en dur dans `src/app/dashboard/page.tsx`. Sur `/practice`, `/account`, `/exams`, `/learn`, etc., il n'y a **aucune navigation** : l'utilisateur est coincé (retour navigateur uniquement).
→ Extraire le header dans un composant partagé (ex. layout d'un groupe `(app)` englobant toutes les pages connectées).

### 3. Bouton « Continuer avec Google » affiché alors que le provider n'est pas configuré
`/api/auth/providers` ne retourne que `credentials` (provider Google conditionné aux env vars, le bouton ne l'est pas). Un clic mène à une page d'erreur NextAuth.
→ Soit masquer le bouton si Google n'est pas configuré (exposer un flag), soit configurer `GOOGLE_CLIENT_ID/SECRET`.

### 4. PWA cassée : manifest non déclaré + icônes manquantes
- `public/manifest.json` existe mais aucun `<link rel="manifest">` n'est émis (`metadata.manifest` absent de `src/app/layout.tsx`) → `/manifest.webmanifest` 404, app non installable.
- Le manifest référence `/icon-192.png` et `/icon-512.png` qui **n'existent pas** dans `public/`.
- Aucun favicon (404 `/favicon.ico` sur chaque page).
→ Ajouter `manifest: "/manifest.json"` dans la metadata, créer les 2 icônes + favicon.

### 5. Promesses RGPD de /legal non tenues dans /account
`/legal` annonce : révocation du consentement audio, export des données et suppression de compte « depuis votre espace ». Or `/account` ne propose que preuve de paiement + code promo.
- L'API `/api/account/consent` existe mais n'a **aucune UI**.
- Export de données et suppression de compte : ni UI ni API.
→ Ajouter ces 3 sections à /account (risque de non-conformité RGPD sinon).

### 6. Page 404 par défaut de Next.js (anglais)
Pas de `not-found.tsx`, ni `error.tsx`, ni `loading.tsx`.
→ Créer un `not-found.tsx` bilingue avec lien retour, un `error.tsx` global, et des `loading.tsx` (squelettes) pour les pages avec fetch.
